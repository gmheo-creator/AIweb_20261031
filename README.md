# 2026-2 예비교수자 과정 웹사이트 — 사용 · 배포 안내

고려대학교 대학원생 대상 「예비교수자 과정」을 소개하고, 수강생이 투표·신청·출석·과제 제출을 할 수 있는 웹사이트입니다.
**서버 없이 동작하는 정적 사이트**라서 파일만 올리면 어디서든 열립니다.

---

## 1. 파일 구성

| 파일 | 하는 일 | 고칠 일 |
|---|---|---|
| `index.html` | 페이지 뼈대 | 거의 없음 |
| **`config.js`** | **사이트의 모든 글·일정·설정** | ✅ 여기만 고치면 됩니다 |
| `style.css` | 색상·디자인 (맨 위 `:root` 에서 색 변경) | 필요할 때만 |
| `app.js` | 소개·커리큘럼·일정·달력 화면 | 없음 |
| `participate.js` | 투표·신청서·로그인·출석·과제 제출·팝업·폭죽 | 없음 |
| `admin.js` | 공지 표시 + 관리자 화면 | 없음 |
| `images/` | 교수자 사진 (`instructor.jpg`) | 사진 넣기 |
| `google-apps-script/` | Google 시트 연결용 코드와 [설치안내](google-apps-script/설치안내.md) | 연결할 때만 |
| `serve.ps1` | 내 PC에서 미리 보기용 간이 서버 (배포에는 필요 없음) | 없음 |
| `build.ps1` | 위 파일들을 **한 파일(`dist/index.html`)로 합치는** 스크립트 | 없음 |
| **`dist/index.html`** | **사이트 전체가 들어 있는 한 파일 버전** — 이 파일 하나만 올리거나 보내면 됩니다 | 직접 고치지 마세요 |

## 1-1. 한 파일 버전 (`dist/index.html`)

`dist/index.html` 에는 디자인·설정·모든 기능(그리고 교수자 사진)이 들어 있어, **다른 파일 없이 이 파일 하나로** 동작합니다.
메일로 보내거나, 파일 하나만 받는 곳에 올릴 때 쓰세요.

- **내용을 바꾸는 방법 1 (관리자 화면, 추천):** 한 파일 버전을 열고 🔒 → 편집 → **💾 설정 파일 → index.html 내려받기**.
  내려받은 새 index.html 로 바꾸면 끝입니다. 교수자 사진도 편집 화면의 **사진 파일 넣기**로 파일 안에 넣을 수 있습니다(1.5MB 이하).
- **내용을 바꾸는 방법 2 (원본 파일 수정):** `config.js` 등을 고친 뒤 아래 명령으로 다시 만듭니다. `images/instructor.jpg` 가 있으면 자동으로 들어갑니다.
  ```bash
  powershell -ExecutionPolicy Bypass -File build.ps1
  ```
- 주의: 관리자 화면에서 고친 내용은 원본 `config.js` 에 자동으로 돌아가지 않습니다. 앞으로 한 파일 버전만 관리할지, 원본 파일을 고쳐 다시 만들지 하나로 정해 두세요.
- 글꼴(Noto Sans KR)은 인터넷에서 불러옵니다. 오프라인에서는 기본 글꼴로 보일 뿐 기능은 그대로입니다.

## 2. 열어 보기

- **가장 간단한 방법:** `index.html` 을 더블클릭해 Chrome·Edge 로 엽니다.
- **내 PC에서 서버처럼 보기:** PowerShell 에서 아래 명령을 실행하고 `http://localhost:5520` 에 접속합니다.
  ```bash
  powershell -ExecutionPolicy Bypass -File serve.ps1 -Port 5520
  ```

## 3. 내용 고치기 — 두 가지 방법

### 방법 A. 관리자 화면에서 (추천)
1. 오른쪽 위 **🔒 자물쇠**를 누르고 비밀번호를 입력합니다. (처음 비밀번호: `sakura2026!` → **공개 전에 꼭 바꾸세요**)
2. **✏️ 사이트 편집**에서 왼쪽 목록(기본 정보, 커리큘럼·주차, FAQ …)을 고르고 칸을 고칩니다.
   항목은 `+ 추가`, `↑ ↓`(순서), `✕`(삭제)로 다룹니다. 주차에는 `+ 과제` 버튼으로 과제를 붙일 수 있습니다.
3. **미리보기 적용**을 누르면 이 브라우저에서 바로 확인됩니다. (화면 아래에 "관리자 미리보기 적용 중" 표시)
4. 마음에 들면 **💾 설정 파일 → config.js 내려받기** 후, 사이트 폴더의 `config.js` 를 그 파일로 바꿉니다.
   → 이제 **모든 방문자**에게 반영됩니다.

> 미리보기는 그 브라우저에만 저장됩니다. 원래대로 돌리려면 화면 아래 **원래대로** 버튼이나 💾 설정 파일 탭의 **원래 config.js 로 되돌리기**를 누르세요.
> 관리자 화면에서 내려받은 config.js 에는 원래 파일의 설명 주석이 빠집니다. 원본 주석이 필요하면 원래 파일을 따로 보관해 두세요.

### 방법 B. config.js 를 직접 편집
메모장·VS Code 로 `config.js` 를 열어 따옴표 안의 글자를 고치고 저장 → 새로고침. 각 항목 위에 설명 주석이 있습니다.

**자주 고치는 곳**
- 수업 날짜: `schedule.startDate`, `weekday`(2=화), `startTime`/`endTime`, 휴강일 `skipDates` → 15주 날짜와 달력이 자동 계산됩니다.
- 주차 내용·참고 영상·과제 마감: `curriculum.weeks`
- 과제 제출 주소(LMS 등): `schedule.submitUrl`
- 투표 주제: `poll.options` · 신청서 항목: `applyForm.fields`
- 안내 팝업·폭죽: `popup`, `welcome`

## 4. 관리자 화면 기능

| 탭 | 할 수 있는 일 |
|---|---|
| ✏️ 사이트 편집 | 사이트 정보와 모든 섹션 내용 고치기 |
| 📢 공지 | 공지 올리기·고정·삭제 (페이지 위쪽 공지사항에 표시) |
| 👥 수강생 명단 | 엑셀에서 복사해 붙여 넣기 / CSV 불러오기 / 저장 / CSV 내려받기. 명단이 있으면 **명단의 학번·이름으로만** 로그인됩니다 |
| ✅ 출석 | 학생 × 주차 출석부(출석·지각·결석, 출석률), **출석부 내려받기**, 출석 기록 CSV |
| 📝 과제 | 과제별 제출 수와 미제출자, 제출 내역 표, **제출 내역 / 제출 현황표 내려받기** |
| 📋 수강 신청 | 신청서 전체 표, **신청 내역 내려받기**, 신청자를 명단에 한 번에 추가 |
| 💾 설정 파일 | config.js 내려받기(백업·배포용) / 불러오기 / 미리보기 되돌리기 |
| 🔑 비밀번호 | 관리자 비밀번호 바꾸기 (바꾼 뒤 config.js 를 내려받아 올려야 다른 기기에도 적용) |

- 내려받는 파일은 모두 **CSV(UTF-8)** 이며 엑셀에서 바로 열립니다. 한글이 깨지지 않고, `010…` 번호의 앞자리 0도 유지됩니다.
- **잠그기**를 누르거나 브라우저 탭을 닫으면 관리자 상태가 풀립니다.

## 5. 데이터 저장 방식

| | 체험 모드 (`mode: "local"`, 기본값) | Google 시트 연결 (`mode: "sheets"`) |
|---|---|---|
| 투표·신청·출석·과제 | 각자의 브라우저에만 저장 | 교수자의 Google 시트에 모두 모임 |
| 과제 파일 | 파일 이름만 기록 | Google 드라이브에 파일 저장 |
| 공지 | config.js 에 넣어 배포해야 모두에게 보임 | 올리는 즉시 모두에게 보임 |
| 명단 | 이 브라우저에만 | 시트 '명단' 탭 |
| 관리자 화면의 내역 | 이 브라우저에서 생긴 것만 | 전체 수강생 |

실제 수업에 쓰려면 **Google 시트 연결을 권장**합니다 → [google-apps-script/설치안내.md](google-apps-script/설치안내.md)

## 6. 배포 (인터넷에 올리기)

**가장 간단한 방법은 `dist/index.html` 파일 하나만 올리는 것입니다.**
여러 파일 버전으로 올리려면 `index.html`, `config.js`, `style.css`, `app.js`, `participate.js`, `admin.js`, `images/` 를 함께 올리세요.
`serve.ps1`, `build.ps1`, `google-apps-script/`, `.claude/`, `README.md` 는 올리지 않아도 됩니다.

### 방법 1. Netlify Drop — 가장 쉬움 (무료, 계정 필요)
1. [app.netlify.com/drop](https://app.netlify.com/drop) 에 접속해 로그인합니다.
2. 사이트 폴더를 브라우저 창에 **끌어다 놓습니다.**
3. 잠시 뒤 `https://○○○.netlify.app` 주소가 생깁니다. 사이트 설정에서 이름을 바꿀 수 있습니다.
4. 내용을 바꿀 때: 사이트의 **Deploys** 화면에 폴더를 다시 끌어다 놓습니다.

### 방법 2. GitHub Pages (무료, GitHub 계정 필요)
1. GitHub 에서 새 저장소(public)를 만들고 **Add file → Upload files** 로 파일들을 올립니다.
2. 저장소의 **Settings → Pages** 에서 Branch 를 `main` / `(root)` 로 정하고 저장합니다.
3. 몇 분 뒤 `https://아이디.github.io/저장소이름/` 으로 열립니다.
4. 내용을 바꿀 때: `config.js` 를 다시 업로드(같은 이름으로 덮어쓰기)합니다.

### 방법 3. 학교·학과 웹 서버
담당 부서에 폴더를 그대로 전달하고 "정적 HTML 사이트"라고 안내하면 됩니다. 별도 프로그램 설치가 필요 없습니다.

> **https 주소로 배포하세요.** 관리자 비밀번호 확인 기능은 https 또는 내 PC 파일(`file://`)·`localhost` 에서만 동작합니다. 위 세 방법은 모두 https 입니다.

## 7. 보안·개인정보 — 꼭 읽어 주세요

- **관리자 비밀번호**는 config.js 에 그대로 들어가지 않고, 되돌릴 수 없는 값(PBKDF2-SHA256, 15만 회)으로만 저장됩니다.
  다만 정적 사이트 특성상 이 잠금은 **화면을 숨기는 장치**입니다. 진짜 데이터(신청·출석·과제)는 Google 시트 쪽에서
  `관리자비밀번호`가 맞아야만 내려주므로 시트 연결 시 안전하게 보호됩니다. **추측하기 어려운 긴 비밀번호**를 쓰세요.
- **수강생 명단·신청서 같은 개인정보는 config.js 에 넣지 마세요.** config.js 는 누구나 볼 수 있습니다. 관리자 화면은 명단을 config.js 에 넣지 않습니다.
- 수강생 로그인은 **비밀번호 없이 학번·이름**으로 구분합니다. 대리 출석을 막으려면 `student.attendance.askCode: true` 로 바꾸고 수업마다 시트 '설정' 탭의 출석코드를 바꿔 주세요.
  성적에 직접 반영하는 출결은 학교 LMS 와 함께 쓰는 것을 권합니다.
- 신청서의 개인정보 동의 문구(`applyForm.fields` 의 `agree`)는 학교 개인정보 처리 기준에 맞게 고쳐 주세요.

## 8. 문제 해결

| 증상 | 해결 |
|---|---|
| 화면이 하얗고 글자만 보임 | `index.html` 만 따로 복사하지 말고 **폴더 전체**를 함께 두세요. |
| 고친 내용이 안 보임 | 새로고침(Ctrl+F5). 관리자 미리보기가 적용된 브라우저라면 화면 아래 **원래대로**를 눌러 보세요. |
| 관리자 비밀번호를 잊음 | 이전에 내려받은 config.js 백업으로 바꾸거나, 개발자에게 `admin` 값 재설정을 요청하세요. |
| "내역을 불러오지 못했습니다" (시트 연결 시) | 시트 '설정' 탭의 `관리자비밀번호`가 사이트 비밀번호와 같은지 확인하세요. |
| 교수자 사진이 안 보임 | `images/instructor.jpg` 이름으로 넣었는지 확인하세요. 없으면 이름 첫 글자가 대신 보입니다. |
| 출석 버튼이 비활성 | 수업 시작 30분 전부터 종료까지만 열립니다. 테스트할 땐 관리자 화면 → 수강생 공간 → `언제나 출석 가능`. |
